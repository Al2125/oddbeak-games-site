ODDBEAK GAMES — WEBSITE STARTER

HOW TO PREVIEW
1. Unzip the downloaded folder.
2. Open the folder.
3. Double-click index.html. It should open in your browser.
4. Edit the files with Visual Studio Code (recommended) or another text editor.
5. Refresh the browser to see your changes.

HOW TO PUBLISH WITH NETLIFY
1. Go to https://app.netlify.com/drop
2. Drag the unzipped project folder (the folder containing index.html) onto the page.
3. Netlify will publish it and provide a public URL.
4. Keep this folder safe. To update the website, edit the files and deploy the updated folder again.

WHERE TO EDIT
- index.html: all text, links, image filenames and page sections.
- style.css: colors, typography, spacing and layout.
- script.js: small interactive features (mobile navigation).

IMAGES
Put your images inside the assets folder (or its subfolders).
When replacing an image, either:
- use the same filename as the placeholder image, or
- change the matching src="..." filename in index.html.

IMPORTANT
- Text inside [square brackets] is placeholder guidance. Replace it with your own writing.
- Replace every href="#" with a real link or remove the link if you do not need it.
- Replace YOUR_EMAIL@example.com with your public contact email.
- The Google Fonts import requires an internet connection. The site still works if the font service is unavailable; it will use fallback fonts.
- This is a static website. It does not collect or store form submissions.
